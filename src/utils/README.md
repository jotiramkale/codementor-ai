Small, pure helper functions with no React or API dependencies:
- `difficulty.js` (Phase 4) — difficulty → Badge tone / bar color
- `time.js` (Phase 9) — formats seconds as "Xm YYs" and dates for display
- `communityStats.js` (Phase 9) — fabricated per-problem median/average
  solving time and a percentile heuristic; deterministic per problem
  (seeded by id) so numbers don't flicker as the solving timer ticks
